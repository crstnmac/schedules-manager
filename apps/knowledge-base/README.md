# jooling Knowledge Base

Product documentation for the jooling scheduling platform. The application uses
TanStack Start, Fumadocs MDX, and the unmodified Fumadocs default UI theme.

Run development server:

```bash
bun run dev
```

The site is available at `http://localhost:3002`; documentation lives under
`/docs`. Run `bun run build` and `bun run check-types` before publishing changes.
