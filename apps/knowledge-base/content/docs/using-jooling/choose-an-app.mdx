---
title: Choose an app
description: Decide whether to use the manager web, worker web, or mobile experience.
---

## Managers

Use the web application for complete Workplace setup, dense weekly scheduling, team administration, policies, reporting, and detailed daily operations. Managers can also use the mobile app for a compact overview, Schedule, Requests, Inbox, and other common actions.

## Workers

Use the mobile app for fast schedule checks, Timecard, Open Shifts, requests, and notifications. The worker web experience provides the same main areas when a desktop or mobile browser is more convenient.

## Shared devices

Use Kiosk only as a shared Location clock. It identifies Workers with a Location PIN and their own Worker PIN and does not replace a personal account for schedules, requests, or messages. Sign out of personal sessions before leaving a shared computer or device.

Your data follows the active Employment and Workplace, not the device. If you work for multiple Workplaces, confirm the Workplace name before acting.
