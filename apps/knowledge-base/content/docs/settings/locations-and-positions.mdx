## Locations

Each Schedule belongs to one Location. Give each Location a recognizable name, correct address, and IANA time zone. Address search helps fill the address and coordinates, and a map shows the pin when coordinates exist.

![Locations list with time zone and address](/screenshots/settings-locations.png)

Select **Add location** to create another site. Each paid Location uses a location seat; if every seat is in use, the sheet offers **Buy location seats** first.

![Add location sheet](/screenshots/settings-locations-add.png)

The Location edit sheet also holds:

- **Geofence radius** in meters, used for clock-in location checks.
- **Hours of operation**, shown on the schedule.
- **Kiosk PIN** for the shared Location clock. The PIN can only be set when you edit an existing Location, and kiosk can be disabled there too.

![Location edit sheet with geofence and kiosk settings](/screenshots/settings-locations-edit.png)

Enforcing the geofence at clock-in is a separate switch under **Settings → Time clock**.

## Positions

Positions describe the role performed on a Shift — Server, Line Cook, and so on. jooling colors shifts by position automatically on the schedule grid.

![Positions list](/screenshots/settings-positions.png)

Select **Add position** and enter a name to create one.

![Add position dialog](/screenshots/settings-positions-add.png)

A Worker needs Position access to be assigned normally or request pickup. That access is granted on the invitation alongside Location access.

## Removing items

jooling prevents removal while a Location or Position is still referenced by Schedules, Shifts, templates, or Workers. Prefer correcting or deactivating access rather than deleting an item that has operational history, and review Workers, drafts, and templates that use it first.
