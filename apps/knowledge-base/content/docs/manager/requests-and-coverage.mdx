## Time off

Open **Time off** to review requests. Each request shows the interval, Leave Type, hours requested, how much balance remains afterwards, the reason, any attached document, and the approval-chain state. Approve or decline the requests assigned to you; requests waiting on another approver are labeled.

![Time off requests awaiting a decision](/screenshots/timeoff.png)

The page also tracks balances, forecasts, encashments, and who is out — all in their own tabs.

## Release and pickup

A **Shift Release** is a worker's request to give up assigned work. The original Worker remains responsible until a replacement is approved and a new version is published. Your Workplace can also auto-accept releases and pickups; where an approval rule applies, the request waits for a Manager decision.

A **pickup** request to take an Open Shift passes eligibility checks first — active Employment, Location and Position access, overlaps, Unavailability. If several people request the same Open Shift, only one valid approved request can take effect.

![Coverage decisions for releases, swaps, and pickups](/screenshots/coverage.png)

## Swaps

A swap moves through proposal, counterpart agreement, and Manager approval. Both Workers keep their original assignments until it is approved.

At approval, jooling checks eligibility again, creates the schedule change, publishes a new version, and notifies affected people. Declining keeps both original assignments.
