---
title: Product glossary
description: Canonical language used throughout jooling.
---

| Term | Meaning |
| --- | --- |
| Workplace | A business organizing hourly work. |
| Location | A physical place operated by a Workplace. |
| Worker | A person employed to perform hourly work. |
| Manager | A person authorized to plan and communicate work. |
| Employment | One person’s relationship and access to one Workplace. |
| Schedule | Planned Shifts for one Location and workweek. |
| Shift | A period of work, normally tied to a Position. |
| Schedule Version | An immutable snapshot created by publication. |
| Successor Draft | A private replacement based on the current version. |
| Notice Window | Lead time in which material changes require acceptance. |
| Acknowledgement | Confirmation that a Worker saw a publication. |
| Shift Acceptance | Explicit agreement to new or materially changed work. |
| Open Shift | Work needing a Worker and offered for pickup. |
| Shift Release | A request to give up work; responsibility remains pending. |
| Shift Swap | A counterpart-agreed exchange requiring Manager approval. |
| Unavailability | A hard constraint on when a Worker can work. |
| Work Preference | A non-binding preference. |
| Time Entry | A record of started and finished work. |
| Attendance Mark | A Manager note such as late, no-show, or sick. |
| Timesheet Approval | Acceptance of a completed Time Entry for hours. |
| Schedule Template | A reusable full-week skeleton for one Location. |
| Shift Template | A reusable Position and time range for one cell. |
| Worker Group | A named Employment set used for filtering. |
| Shift Tag | A label attached to a Shift. |
| PTO Balance | Remaining Time-off hours by Leave Type and Employment. |
| Geofence | A Location radius required for mobile clock start. |
| Kiosk | A shared Location clock using Location and Worker PINs. |

Use these terms when discussing scheduling with your team so requests and responsibilities remain clear.
